
# 📊 Tech Layoffs 2026 Analysis (SQL + Power BI)

## 📌 Project Overview

This project focuses on analyzing global tech layoffs data for the year 2026 using **SQL for data analysis** and **Power BI for data visualization**.

The aim is to uncover patterns, trends, and insights related to layoffs across companies, industries, and countries, and present them through an interactive dashboard.

## 🎯 Objectives

* Analyze total layoffs across companies and industries
* Identify top companies affected by layoffs
* Study layoffs distribution across countries
* Understand trends over time (monthly & yearly)
* Explore the relationship between funding and layoffs
* Build an interactive Power BI dashboard for insights

## 🗂 Dataset Description

The dataset contains information about layoffs in the tech industry, including:

* Company Name
* Industry / Sector
* Country / Location
* Number of Employees Laid Off
* Percentage of Workforce Laid Off
* Date of Layoff
* Funds Raised
* Company Stage 


## 🛠 Tools & Technologies Used

* **SQL** – Data extraction and analysis
* **Power BI** – Data visualization and dashboard creation


## 📊 Dashboard Features

The Power BI dashboard provides:

* 📌 **Total Layoffs KPI**
* 🏢 **Company-wise Layoffs Analysis**
* 🏭 **Industry-wise Comparison**
* 🌍 **Country-wise Distribution (Map View)**
* 📈 **Layoffs Trend Over Time**
* 🎛️ **Interactive Filters (Year, Country)**

## 🔍 Key Insights

* Certain industries experienced significantly higher layoffs compared to others
* A few companies contributed heavily to total layoffs
* Layoffs showed noticeable spikes during specific months
* Countries varied widely in layoff impact
* Some companies reported **100% workforce layoffs**, indicating shutdowns
* No strong linear relationship was observed between funding and layoffs in some cases
